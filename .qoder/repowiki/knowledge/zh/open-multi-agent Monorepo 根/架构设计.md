根目录作为私有 npm workspace 根（`workspaces: ["packages/*"]`），将各子包以独立 npm 包形式发布（如 `@open-multi-agent/core`），并通过顶层 `package.json` 的 scripts 统一编排：`build`/`test`/`lint` 借助 `--workspaces --if-present` 转发到子包；`pretest` 先执行 `scripts/example-catalog.test.mjs` 与 `scripts/validate-example-catalog.mjs` 校验示例清单 schema，再运行子包测试；评估与可观测性冒烟脚本（`test:eval-examples`、`bench:observability:ci`、`test:observability-examples`）由根直接调用 `scripts/` 下的 Node 脚本驱动。CI 工作流位于 `.github/workflows/ci.yml`，复用同一组脚本保证仓库级一致性。
